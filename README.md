## Project Overview

The Research and Rescue Hexapod is a proposed six-legged robotic platform designed to assist with search-and-rescue activities in environments where access may be difficult, unstable, or potentially unsafe for human responders.

The project explores the use of a hexapod structure to provide stable movement across challenging terrain while supporting the potential inspection and exploration of areas affected by incidents such as building collapses or other hazardous situations.

For the elimination stage, the project combines robotic movement, kinematic modelling, software development, and physical design. The current source code includes an existing open-source hexapod simulation and kinematics implementation that will be used as a foundation for further development.

The source code will be altered and adapted to correspond with the requirements of the final robot design, including the mechanical and electronic requirements specified in Policy C and the components available to the team.

---

## Project Objectives

The main objectives of the Research and Rescue Hexapod are to:

- Develop a six-legged robotic platform for search-and-rescue applications.
- Explore hexapod movement and leg positioning through kinematic calculations.
- Develop a software foundation for modelling and controlling robot movement.
- Investigate the feasibility of using a hexapod platform in difficult or hazardous environments.
- Adapt the software to correspond with the final mechanical and electronic design.
- Develop a feasible prototype using the components available to the team.
- Ensure that the final design complies with the requirements and constraints of Robo Rumble 2026.
- Document the mechanical, electronic, programming, and practical aspects of the project.

Software and Programming Approach

The current software foundation is based on Python and Plotly Dash and provides a browser-based hexapod simulation and kinematic modelling environment.

The existing implementation includes functionality related to:

Forward kinematics.
Inverse kinematics.
Hexapod leg positioning.
Robot movement.
Robot pose and orientation.
Three-dimensional visualisation.
Adjustable robot dimensions and movement parameters.

The existing implementation is being used as a starting point rather than as the completed software solution for the Research and Rescue Hexapod.

The source code will be modified to match the final mechanical design, joint configuration, electronic components, and programming requirements identified during the development of the project and specified in Folder C.

Development Approach

The project will follow the following general development process:

Establish a hexapod kinematic and simulation foundation.
Analyse the movement requirements of the proposed robot.
Determine the components available to the team.
Finalise the mechanical and electronic configuration.
Adapt the existing source code to the final robot design.
Develop the required control and movement logic.
Integrate the software with the physical hardware.
Test and refine the robot's movement and functionality.
Document the completed design and implementation.
Safety and Competition Requirements

The final Research and Rescue Hexapod will be developed according to the applicable Robo Rumble 2026 requirements.

The design will account for:

Maximum footprint requirements.
Weight requirements.
An accessible ON/OFF switch.
An emergency stop (E-Stop) mechanism capable of immediately cutting power.
Clear documentation and annotation of the required safety mechanisms.
The applicable requirements specified in Policy C.

The final implementation will be evaluated against the competition requirements before submission.
